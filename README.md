## 📌 Sobre o projeto

O **JS Form Validations** é um projeto Front-End desenvolvido para praticar a criação e validação de formulários utilizando **HTML, CSS e JavaScript**.

A aplicação possui uma interface de cadastro moderna e permite validar diferentes informações preenchidas pelo usuário.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em **Desenvolvimento Front-End**, colocando em prática conceitos de manipulação do DOM, eventos e lógica de programação com JavaScript.

## ✨ Funcionalidades

- ✅ Cadastro de usuário
- ✅ Validação dos campos do formulário
- ✅ Validação de nome e sobrenome
- ✅ Validação de data de nascimento
- ✅ Validação de e-mail
- ✅ Confirmação de senha
- ✅ Validação de gênero
- ✅ Feedback visual para campos inválidos
- ✅ Manipulação do DOM com JavaScript
- ✅ Interface responsiva
